# Retired traditions

Traditions we haven't seen lately, or that a source says ended. Know one that's still going? Tell us.

!!! abstract "TL;DR"
    - Most of these are traditions whose sources stop. **Last seen** is the latest mention we've found so far, which doesn't mean it stopped.
    - A few have a source that says they ended. Those say so, with the source.
    - Wiess did this sorting first. The 1997 website had a list called **Traditions That Sadly Seem To Be Dying Out** [@riceinfo-traditions-1997].
    - Know one of these is still alive? Tell us with the "Add your story" button.

## The 1990s were already sorting

The 1997 site's "Dying Out" list had Talleyboo, *The Princess Bride* and No-Theme Wiess. Its note on Talleyboo: "when was the last time anybody at Wiess did anything *really* disgusting?" [@riceinfo-traditions-1997]

The same site already spoke of two as gone. "I'm glad 'dangling' doesn't happen anymore" [@riceinfo-traditions-1997]. Jock Row was "now defunct" in the 1994 handbook text [@riceinfo-history].

By the end of 1999 Ray Wagner had moved Unnecessary Tie Day and Norse Night onto the "Dying Out" list and rescued No-Theme Wiess [@riceinfo-traditions-1999]. The site's comfort still works: "somebody'll come up with something else cool to do. Change can be good." [@riceinfo-traditions-1997]

??? info "Arguments & loose ends"

    **Named once, no page.** Three things on the 1997 lists have only a name:

    - ***The Princess Bride***, "Dying Out" in 1997 and 1999. Probably a screening, but no source says so [@riceinfo-traditions-1997].
    - **Wiess Films**, "We'd Sure Like To See Continue" in 1997 and 1999 [@riceinfo-traditions-1997].
    - **Four-square in the Acabowl**: "Foursquare—Good Fourplay" in the 1994 glossary, and on the 1997 keep list [@handbook-1994] [@riceinfo-traditions-1997]. It belongs with [the Acabowl](../../places/acabowl.md).

    **Still don't know.**

    - Any of these may have kept going in 2000–2003, between the last old website and the first O-Week book we have.
    - The printed 1994 Freshman Handbook, and older ones, would show which were still taught to freshmen [@handbook-1994].
    - The Thresher after 1999 hasn't been searched for these names [@thresher-web]. The pre-1994 Thresher has, and it turned up early dates for several (see each page).
